# Adventure Works Sales Insights | Tableau Dashboard

An interactive Tableau dashboard analyzing the Adventure Works Cycles dataset. This project highlights key business metrics such as sales, profit, customer distribution, and product performance across various time periods and regions.

## 📊 Dashboard Overview

This Tableau dashboard provides:

- **Total Sales and Profit Summary**
- **Year-wise and Quarter-wise Sales Trends**
- **Production Cost vs Sales by Month**
- **Country-wise Sales Breakdown**
- **Interactive Filters for Products**
- **Sales vs Profit Toggle for Performance Analysis**

## 🛠️ Tools & Technologies

- **Excel** – for cleaning and preparing the data
- **Tableau** – for building the dashboard and data visualization
- **Adventure Works Dataset** – Microsoft's sample dataset for business analytics

## 📌 Objective

The goal of this project is to demonstrate data analysis and visualization capabilities using Tableau. The dashboard helps uncover meaningful business insights and supports strategic decision-making.

## 🚀 How to Use

3. Explore filters, KPIs, and visualizations interactively.

## 📈 Insights Generated

- Peak sales observed in **2013**, with strong contributions from **Q4**.
- **United States** and **Australia** are top-performing markets.
- Monthly trends reveal consistent gaps between production costs and sales revenue, aiding in margin analysis.
- Users can drill down by **product category** and **region**.
